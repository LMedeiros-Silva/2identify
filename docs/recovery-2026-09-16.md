## 5. Causa raiz dos três erros do Admin

O commit WIP contém testes e a parte API/Operator da Gestão de EPI, mas não contém a implementação correspondente do Admin. Não foi localizado módulo equivalente movido/renomeado nem uma definição anterior do evento nas referências Git disponíveis.

O desenho e plano versionados, de 25/08/2026, preveem explicitamente criar o domínio ppe_management, o consumidor HTTP/realtime, serviço, worker, controlador e página. A navegação do Admin ainda apontava a um placeholder.

Os três erros compartilham essa causa:

1. test_ppe_management_api.py importa um domínio ainda ausente.
2. test_ppe_management_ui.py importa esse mesmo domínio e depende da página ainda ausente.
3. test_realtime_protocol.py espera PpeSessionUpdatedEvent via app.domain, mas a classe não estava definida nem exportada. Portanto, não era apenas um reexport esquecido.

O evento foi definido uma única vez no domínio realtime do Admin e reexportado. O domínio PPE ficou no local previsto pelo desenho. Nenhum contrato de API/Operator foi duplicado entre projetos por import de código: o Admin possui seu DTO de transporte, convertido para seu domínio, como os recursos existentes.
